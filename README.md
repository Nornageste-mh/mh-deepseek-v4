# mh-deepseek-v4

AI 辅助生成的 Vibe coding 实验品，非官方、无维护承诺，用前自担风险。
正经用途请看下方推荐：

## 推荐项目

### DeepSeek 官方

- **DeepSeek Harness** — 万物皆插件：模型/工具/技能/UI 全可替换。`npx @deepseek-ai/dsh web` → http://127.0.0.1:3080
  https://github.com/deepseek-ai/deepseek-harness

### 全能型 Agent

- **Hermes Agent**（Nous Research）— 自学习循环、自主创建技能、多端接入。`curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash`
  https://github.com/NousResearch/hermes-agent
- **OpenClaw** — 本地优先自主助手，WhatsApp/Telegram/Slack/iMessage 执行任务。`curl -fsSL https://openclaw.ai/install.sh | bash`
  https://github.com/openclaw/openclaw
- **Goose**（Block）— 可实际安装/执行/编辑/测试，支持任意 LLM。`curl -fsSL https://github.com/aaif-goose/goose/releases/download/stable/download_cli.sh | bash`
  https://github.com/aaif-goose/goose
- **AutoGPT** — 老牌自主 Agent。`curl -fsSL https://setup.agpt.co/install.sh -o install.sh && bash install.sh`
  https://github.com/Significant-Gravitas/AutoGPT

### 终端 / 编码 Agent

- **Codex CLI**（OpenAI）— 终端编码 Agent，支持 OpenAI 兼容 API（含 DeepSeek）。`curl -fsSL https://chatgpt.com/codex/install.sh | sh`
  https://github.com/openai/codex
- **Aider** — Git 感知结对编程。`pip install aider-chat`
  https://github.com/Aider-AI/aider
- **Open Interpreter** — LLM 本地运行代码。`pip install open-interpreter`
  https://github.com/OpenInterpreter/open-interpreter
- **Continue** — IDE 内编码 Agent。插件市场搜 "Continue"
  https://github.com/continuedev/continue
- **gptme** — 终端 Agent。`pipx install gptme`
  https://github.com/gptme/gptme

### 框架 / 命令行

- **Microsoft AutoGen** — 多 Agent 编排框架。`pip install -U "autogen-agentchat" "autogen-ext[openai]"`
  https://github.com/microsoft/autogen
- **CrewAI** — 多角色 Agent 协作。`pip install crewai`
  https://github.com/crewAIInc/crewAI
- **LLM**（Simon Willison）— 命令行调用各类 LLM。`pip install llm`
  https://github.com/simonw/llm
